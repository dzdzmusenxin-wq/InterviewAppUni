# TabBar 图标说明

此目录用于存放 TabBar 的图标文件。

## 需要的图标文件

### 默认状态图标
- `home.png` - 首页（基础）默认图标
- `scene.png` - 场景练习默认图标
- `algo.png` - 算法练习默认图标
- `profile.png` - 我的默认图标

### 选中状态图标
- `home-active.png` - 首页（基础）选中图标
- `scene-active.png` - 场景练习选中图标
- `algo-active.png` - 算法练习选中图标
- `profile-active.png` - 我的选中图标

## 图标规范

- 格式：PNG
- 尺寸：建议 48x48px 或 64x64px
- 颜色：
  - 默认状态：灰色系 (#64748B)
  - 选中状态：主色调 (#4F46E5)
- 风格：线性图标或填充图标，保持一致

## 推荐图标来源

1. [Iconfont](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
2. [Heroicons](https://heroicons.com/) - 开源图标库
3. [Feather Icons](https://feathericons.com/) - 简洁线性图标
4. [Tabler Icons](https://tabler-icons.io/) - 免费开源图标

## 使用说明

将下载好的图标文件放入此目录，确保文件名与上述列表一致。图标将在应用底部 TabBar 中自动显示。
